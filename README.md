# ECO-Equity: Mudanças Climáticas e Desigualdade de Gênero  

Este site apresenta um mapa interativo que exibe dados sobre mudanças climáticas e desigualdade de gênero em diferentes países. Ele permite visualizar informações relevantes ao clicar em cada país, relacionando dados climáticos com participação política, alfabetização feminina e outros indicadores sociais.  

🔗 **Acesse o site aqui:** ([https://link-do-seu-site.com](https://agathaassis.github.io/Eco-equity/)

## 🚀 Tecnologias Utilizadas  
- HTML, CSS, JavaScript  
- APIs: World Bank, UN Data
